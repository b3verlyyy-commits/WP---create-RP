MC Converter — Android-приложение (APK)

Вариант 1 — без Android Studio (нужен ПК и аккаунт github.com):
1. Создай на GitHub новый репозиторий.
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку .github
   (Add file -> Upload files, перетащи файлы и папки).
3. Открой вкладку Actions -> Build APK. Сборка стартует сама (около 3-5 минут).
4. Внутри завершённой сборки скачай артефакт MC-Converter-apk, в нём app-debug.apk.
5. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

Вариант 2 — Android Studio: File -> Open -> эта папка, затем Build -> Build APK(s).

Файлы сохраняются в Загрузки/MC Converter. Нужен Android 10 или новее.
